# 时间投入复盘看板设计

日期：2026-06-10

## 目标

为“时间投入”模块增加一个复盘看板，用于回答三类问题：

- 这段时间我到底把时间投到了哪里
- 这段时间生产 / 消费结构是否失衡
- 我在天、周、月尺度上该如何复盘

该看板不是运营 BI，不追求复杂分析能力，也不试图自动解释用户状态。第一版只提供可信、低噪音、可直接回看的复盘视角。

## 产品定位

- 看板属于“时间投入”模块内部，不是容器首页能力。
- 看板服务“事后理解”，不干扰“开始时零阻力”的记录主流程。
- 第一版默认以天、周、月复盘为主，同时支持自定义时间范围。
- 第一版优先展示时间结构，不优先做文本洞察。

## 信息架构

“时间投入”模块拆为两个平级页签：

- `记录`
  - 负责开始、进行中状态、结束裁决、今日累计
  - 服务“当下动作”
- `复盘`
  - 负责时间范围选择、区间总账、按天趋势、最近生产备注
  - 服务“事后理解”

默认进入 `记录` 页，不自动切换到 `复盘`。

## 复盘页第一版范围

第一版 `复盘` 页只包含三块内容：

1. 时间范围栏
2. 总账卡片
3. 按天趋势
4. 最近生产备注

虽然页面实际是四个区块，但其结构上可视为三层：

- 顶部：时间范围控制
- 中部：总账 + 趋势
- 底部：记录回看

## 时间范围

### 默认时间尺度

优先支持：

- 今天
- 本周
- 本月

### 扩展时间尺度

支持自定义起止日期区间。

### 交互原则

- 全页共享一个时间范围
- 切换时间范围时，全页数据同步刷新
- 不允许每个卡片单独切范围

这样做的目的是让复盘口径统一，避免用户在同一屏里同时看多个统计口径。

## 第一版展示内容

### 1. 总账卡片

展示四个指标：

- 总投入时长
- 生产时长
- 消费时长
- 生产占比

### 总账卡片回答的问题

- 这一段时间总体投入了多少
- 其中真正被用户判为生产的有多少
- 消费占比是否过高

### 第一版明确不放入总账区的指标

- session 数
- 平均单段时长
- 中位数
- 连续天数

这些指标当前信息增益不够高，会增加页面噪音。

### 2. 按天趋势

使用按天聚合后的趋势视图表达该区间内每天的结构变化。

每一天至少包含：

- 当天生产时长
- 当天消费时长
- 当天总投入时长

### 按天趋势回答的问题

- 哪几天生产更厚
- 哪几天消费偏高
- 波动主要发生在哪几天

### 表达原则

- 第一版只做一张主趋势图
- 图表重点是“看出结构”，不是复杂交互
- 不引入额外的分析维度

### 3. 最近生产备注

展示当前时间范围内最近若干条 `production` session，按结束时间倒序排列。

每条展示：

- 日期时间
- 本段时长
- `production_note`

### 最近生产备注回答的问题

- 最近我到底产出了什么
- 当前这段复盘周期里，生产记录是否有真实内容支撑

### 定位说明

该区块是“记录回看”，不是文本分析区。

第一版不做：

- 高频词
- 关键词抽取
- 自动主题归纳

因为当前数据字段只有 `production_note`，直接做文本洞察容易造成虚假解释。

## 数据聚合能力

第一版只需要四类聚合能力。

### 1. 区间总账

输入：

- 一个时间范围

输出：

- 总投入时长
- 生产时长
- 消费时长
- 生产占比

### 2. 按天汇总

输入：

- 一个时间范围

输出：

- 该范围内每一天的生产时长
- 该范围内每一天的消费时长
- 该范围内每一天的总投入时长

### 3. 最近生产记录

输入：

- 一个时间范围

输出：

- 当前范围内最近若干条生产记录
- 每条记录包含结束时间、时长、生产备注

### 4. 时间范围解析

支持：

- 今天
- 本周
- 本月
- 自定义起止日期

该能力负责统一全页口径，不让每个视图重复定义日期边界。

## 第一版明确不做

- 不做按小时分布
- 不做单段时长分布
- 不做 session 数 / 平均时长 / 中位时长
- 不做热力图
- 不做高频词
- 不做自动复盘结论
- 不做异常检测
- 不做筛选器组合
- 不做导出

## 设计原则

- 复盘页必须比记录页“信息更丰富”，但不能重到像 BI 仪表盘
- 所有展示都围绕真实 session 数据，不推断不存在的业务语义
- 文本区只作为原始回看抓手，不伪装成智能洞察
- 复盘服务理解，不服务评判

## 成功标准

第一版看板上线后，应至少满足以下标准：

- 用户能在一个统一时间范围下快速看懂总投入结构
- 用户能从按天趋势中定位失衡或波动出现在哪几天
- 用户能从最近生产备注中快速回忆最近实际做了什么
- 记录页的零阻力开工体验不受影响

## 后续扩展方向

如果第一版稳定可用，后续再考虑：

- 按小时分布
- 单段时长分布
- 最长生产 session
- 高消费日提示
- 更强的复盘辅助提示

这些能力属于第二阶段，不进入当前实现范围。
